Comment veux-tu utiliser Lumen ?

Crée ton profil : il porte ton workspace (sandboxes, bureau, mémoire). Le mot de passe protège l'ouverture de session — il est vérifié côté système, jamais stocké en clair.

Sans mot de passe, la session s'ouvre d'un simple clic. D'autres profils pourront être ajoutés plus tard dans Paramètres → Profil.

Installe les 5 raccourcis via iCloud. Pour chacun : clique sur Installer, puis Ajouter le raccourci dans la fenêtre macOS. Clique ensuite sur Vérifier.

Ces raccourcis servent à la source Modèle Apple (réponses, énonciation, dictée, mode Action). Si tu utilises Ollama, ils ne sont pas nécessaires.

Installe les 5 raccourcis d'un coup, puis vérifie automatiquement.

Les fonctionnalités d'IA d'Apple doivent être activées dans macOS pour que la source « Modèle Apple » fonctionne.

  1. Ouvre les Réglages Système (bouton ci-dessous).
  2. Va dans les réglages d'IA d'Apple (section Siri).
  3. Active les fonctionnalités d'IA et attends le téléchargement des modèles (quelques minutes).
  4. Assure-toi que ta région et la langue sont compatibles (ces fonctionnalités ne sont pas disponibles partout).

Astuce : si le bouton n'ouvre pas exactement la bonne section, ouvre les Réglages Système et cherche les réglages d'IA d'Apple.

Lumen va préparer un moteur d'IA local, privé et gratuit. Aucune ligne de commande.

Voix active

Voici les boutons de la barre :

  • Paramètres — source d'IA, modèles, thème, prompt système, etc. La pastille de couleur indique l'état de connexion (vert = prêt, rouge = hors-ligne / modèle Ollama manquant).
  • Historique — retrouve et rouvre tes conversations sauvegardées (avec le modèle utilisé).
  • Notifications — affiche les résultats renvoyés par les tâches du Heartbeat.
  • Thème clair / sombre — bascule l'apparence verre clair ou sombre.
  • Mode Action (Modèle Apple) — envoie via ton Routeur d'Actions au lieu d'une réponse classique. Jaune = activé.
  • Énoncer automatiquement — lit à voix haute chaque réponse dès sa réception. Vert = activé.
  • Heartbeat — active/désactive une tâche d'arrière-plan programmée. Rouge pulsé = actif.
  • Dictée vocale — place le curseur dans la barre et lance la dictée macOS.

Selon la taille de la barre (Paramètres → Taille de la barre), certains boutons se replient dans le menu Plus d'outils à droite. En mode grand, tout est affiché.

Fonctions utiles dans la discussion :

  • Énoncer un message — l'icône haut-parleur sur chaque réponse la lit à voix haute.
  • Réessayer — sous une réponse en erreur, relance la requête en retirant l'erreur du contexte.
  • Markdown — les réponses sont mises en forme (titres, listes, gras, code…).
  • Prompt système — dans les Paramètres, définis des instructions envoyées avant ton 1ᵉʳ message.
  • Pastille modèle — à droite de la barre.
  • Déplacement — glisse la barre n'importe où, jusqu'en haut de l'écran ; elle reste au-dessus des autres apps.
  • Passe-clic — les zones vides autour de l'orbe et de la barre laissent passer les clics vers le bureau.

Le Heartbeat exécute une tâche à intervalle régulier (un « CRON » intégré). Idéal pour automatiser une tâche d'arrière-plan.

  1. Prépare ce que le Heartbeat doit exécuter : un workflow Fluxo nommé Heartbeat (disponible sur toutes les plateformes), ou sur Mac, un raccourci de l'app Raccourcis.
  2. Ouvre les Paramètres de Lumen → section Heartbeat.
  3. Active le heartbeat, choisis le moteur (Fluxo ou Raccourci) et la fréquence d'exécution.
  4. Tu peux aussi l'activer/désactiver via le bouton Heartbeat de la barre.
  5. À chaque exécution, le résultat est collecté dans la cloche de notifications.

Astuce : fais en sorte que ton workflow ou raccourci renvoie un texte en sortie pour le retrouver dans la cloche.
