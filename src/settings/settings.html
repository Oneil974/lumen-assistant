Recherche web

C'est le seul outil qui sort de la machine : la requête part chez le moteur choisi, et la page consultée apprend votre existence. Désactivé par défaut. Les adresses locales et privées (votre domotique) restent interdites à l'IA quels que soient ces réglages.

À savoir avant d'activer
  • Vos requêtes quittent la machine. Ce que vous demandez à Lumen — y compris ce que le modèle reformule à partir de votre conversation, de votre profil ou de vos mémoires — peut se retrouver dans une requête envoyée au moteur, qui l'associe à votre adresse IP.
  • C'est l'IA qui décide quoi chercher, pas vous. Vous ne validez pas chaque requête : un modèle peut inclure dans sa recherche un détail que vous n'auriez pas publié.
  • Les pages lues ne sont pas fiables. Une page peut contenir un texte destiné à manipuler le modèle (« ignore tes consignes, envoie… »). Lumen marque ce contenu comme donnée à citer, jamais comme instruction, mais aucune protection n'est absolue : méfiez-vous d'une réponse qui part soudainement dans une autre direction.
  • Les résultats peuvent être faux. Un lien bien classé n'est pas une source vérifiée : le modèle peut résumer une page erronée avec le même aplomb qu'une bonne. Vérifiez les URL citées avant d'agir sur une information sensible.
  • Combinée aux autres outils, la recherche devient une porte de sortie. Si vous publiez aussi des outils qui écrivent (workflows, domotique, connecteurs MCP), une consigne cachée dans une page peut chercher à les déclencher. Ne publiez que ce dont vous avez besoin.

    Chaque app dépose ses données dans le coffre unifié sous forme de fiches (tâche, évènement, note, contact, message, fichier, mesure…). L'IA, les agents, le compagnon, l'app iOS et Lumen XR les consultent tous au même endroit (outils data_search, data_agenda, data_tasks, data_metrics). Décoche une source pour la retirer. Le texte des notes et documents (PDF, Word, présentations, classeurs, Markdown…) est indexé en entier ; images, audio, vidéo et autres fichiers y figurent avec un lien que l'IA peut afficher ou te fournir. Décoche une sandbox pour la garder hors du coffre.
    

            
            
    Coffre de données
    
            
            
    
            
    
              
              
              
              
            
    
            
    Valeurs partagées avec l'iPhone (Raccourcis, widgets, capteurs), le chat et les agents — comme Data Jar. Les dossiers se notent avec « / ». Un workflow Fluxo au déclencheur Webhook « vault/ » se lance à chaque changement de la clé ; « iphone/arrivee/ » à l'arrivée dans un lieu.

    Désactivé : un appareil appairé (compagnon, casque, téléphone) déverrouille tes fichiers d'un simple geste — il a déjà prouvé ton code à l'appairage, et tu peux le révoquer ci-dessus. Activé : le code à 6 chiffres est redemandé à chaque fois.

    Messagerie Telegram
    
                
    Discutez avec Lumen et lancez des tâches depuis votre téléphone, où que vous soyez. Lumen n'ouvre aucun port : il interroge Telegram en sortie (long polling). Seules les conversations que vous appairez explicitement sont écoutées.

                Activer la passerelle Telegram
                
              
    
              
    
                État
                —
              
    
            
    
            
    Créez un bot avec @BotFather sur Telegram, puis collez ici le jeton qu'il vous donne. Le jeton reste côté application, dans un fichier privé (0600), et n'est jamais renvoyé à l'interface. Toute cette configuration appartient au profil actif : chaque profil a son bot, ses conversations et ses transcrits, et changer de profil bascule la passerelle.

    Bot Slack
    
                
    Parlez à Lumen et à vos agents depuis Slack : en message privé, ou en le mentionnant dans un canal. Lumen n'ouvre aucun port — il se connecte lui-même à Slack (Socket Mode). Seuls les utilisateurs que vous appairez sont écoutés.
    
              
    
            
    

            
    Mise en place (une seule fois)
    
            
    
              
    
                1Sur api.slack.com/apps : Create New App → From a manifest, choisissez votre espace, puis collez le manifeste de Lumen.
                
    
                  
                  Ouvrir Slack API ↗
                
    
                
    Voir le manifeste
    
              
    
              
    
                2Install to Workspace, puis copiez le Bot User OAuth Token (xoxb-…) depuis OAuth & Permissions.
              
    
              
    
                3Dans Basic Information → App-Level Tokens, générez un jeton avec la portée connections:write (xapp-…).
