# ui_set_sprite_frames

Définit les images utilisées pour l'animation d'un sprite.

## Description
Associe une liste d'images à un sprite créé avec `ui_add_sprite`.

## Entrées
- **ID** : field_input – identifiant du sprite.
- **FRAMES** : input_value – liste d'images (URLs ou fichiers importés).

## Sortie
- Aucune
