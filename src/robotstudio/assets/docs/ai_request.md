# ai_request

Query Ollama LLM and store the reply

## Description
Send a text prompt to the Ollama language model server and save the
response. A simple way to add AI-generated text to your projects.

## Entrées
- **URL**: input_value (type String)
- **MODEL**: input_value (type String)
- **PROMPT**: input_value (type String)
- **STREAM**: input_value (type Boolean)
- **THINK**: input_value (type Boolean)
- **VAR**: field_variable

## Sortie
- Aucune
