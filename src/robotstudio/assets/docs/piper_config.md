# piper_config

Configure Piper TTS

## Description
Set up the Piper text-to-speech engine with your preferred voice model
and options. Do this once before speaking any text.

## Entrées
- **MODEL**: input_value (type String)
- **CONF**: input_value (type String)
- **CUDA**: input_value (type Boolean)

## Sortie
- Aucune
