# ml_predict_yolo

Send image to YOLO detection API

## Description
Send an image to a YOLO-based cloud service for object detection and
store the list of results. Great for complex vision tasks when local
hardware is limited.

## Entrées
- **URL**: input_value (type String)
- **MODEL**: input_value (type String)
- **IMAGE**: input_value (type String)
- **VAR**: field_variable

## Sortie
- Aucune
