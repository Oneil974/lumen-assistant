# ml_predict_image

Send base64 image to ML inference API

## Description
Upload an image (encoded in base64) to an online ML service and get back
the prediction. Useful for image recognition tasks when you do not have
enough power locally.

## Entrées
- **URL**: input_value (type String)
- **MODEL**: input_value (type String)
- **IMAGE**: input_value (type String)
- **VAR**: field_variable

## Sortie
- Aucune
