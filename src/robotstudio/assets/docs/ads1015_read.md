# ads1015_read

Read ADS1015 channel

## Description
Read an analog value using the ADS1015 analog-to-digital converter.
Select which channel you want, then use the number for sensors that
output voltage such as light or distance sensors.

## Entrées
- **CHAN**: field_dropdown, options: 0, 1, 2, 3
