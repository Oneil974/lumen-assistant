# rpi_ultrasonic

Read ultrasonic sensor

## Description
Measure distance using an HC-SR04 or similar ultrasonic sensor. 
By sending a short sound pulse and timing the echo, the Pi can estimate how far away an object is. Ideal for obstacle detection on robots.

## Entrées
- **TRIG**: field_number
- **ECHO**: field_number
