# ml_local_predict_yolo

Run YOLO detection locally

## Description
Detect objects in an image using a YOLO model stored on your device.
Great for quick experiments with real-time vision without relying on the
internet.

## Entrées
- **MODEL**: input_value (type String)
- **IMAGE**: input_value (type String)
- **VAR**: field_variable

- Aucune
