# ml_predict

Send sample to ML inference API

## Description
Send data to a remote machine learning service and store the result. This
is useful for heavy models that are difficult to run on a Raspberry Pi.

## Entrées
- **URL**: input_value (type String)
- **MODEL**: input_value (type String)
- **SAMPLE**: input_value (type String)
- **VAR**: field_variable

## Sortie
- Aucune
