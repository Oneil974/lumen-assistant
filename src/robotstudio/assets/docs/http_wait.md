# http_wait

Wait for HTTP request and store field

## Description
Pause your program until a request hits the specified endpoint, then
save one of the values it contains. Ideal for reacting to buttons or
web forms sent from another device.

## Entrées
- **ENDPOINT**: input_value (type String)
- **FIELD**: input_value (type String)
- **VAR**: field_variable

## Sortie
- Aucune
