# rpi_gpio_write

Simple GPIO control.

## Description
Drive any device connected to a Raspberry Pi GPIO pin by forcing the line HIGH (3.3V) or LOW (0V).

## Entrées
- **PIN**: field_number – BCM pin number to control.
- **STATE**: field_dropdown – select HIGH (3.3V) or LOW (0V).

## Sortie
- Aucune
