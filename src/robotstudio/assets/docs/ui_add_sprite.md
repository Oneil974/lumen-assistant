# ui_add_sprite

Ajoute un sprite animé dans l'interface.

## Description
Crée un sprite dans la scène UI. Les images de frames seront définies ensuite avec `ui_set_sprite_frames`.

## Entrées
- **ID** : field_input – identifiant du sprite.
- **X** : field_number – position horizontale.
- **Y** : field_number – position verticale.

## Sortie
- Aucune
