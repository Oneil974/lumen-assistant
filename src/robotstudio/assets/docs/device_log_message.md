# device_log_message

Envoie un message de log vers la plateforme.

## Description
Publie un message (info, warning, error) qui apparaît dans la section Logs des devices.

## Entrées
- **URL** : input_value – URL de la plateforme (ex: `http://192.168.1.10:5010`).
- **DEVICE** : input_value – ID du device configuré.
- **LEVEL** : field_dropdown – niveau du message (info, warning, error).
- **MESSAGE** : input_value – texte du log.

## Sortie
- Aucune
