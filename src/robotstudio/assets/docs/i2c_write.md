# i2c_write

Write to I2C device

## Description
Send a value to an I2C device by specifying its address and register.
Use this for controlling displays, digital potentiometers, and other
peripherals that support the I2C protocol.

## Entrées
- **ADDR**: field_number
- **REG**: field_number
- **VAL**: field_number
