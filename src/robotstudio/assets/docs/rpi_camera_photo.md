# rpi_camera_photo

Capture photo with Pi camera

## Description
Use this block to take a still image with the Raspberry Pi Camera Module. 
Specify a file name for the picture and, if needed, the width and height of the captured frame. 
This is useful for quick snapshots from a robot or a simple security setup. 📷

## Entrées
- **FILE**: field_input
- **W**: field_number
- **H**: field_number

## Sortie
- Aucune
