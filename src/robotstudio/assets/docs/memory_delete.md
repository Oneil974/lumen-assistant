# memory_delete

Supprime une valeur de la mémoire locale du robot.

## Description
Efface une entrée stockée dans la base SQLite locale.

## Entrées
- **SERVER** : input_value – chemin du fichier SQLite.
- **NAMESPACE** : input_value – nom d'espace.
- **KEY** : input_value – clé à supprimer.

## Sortie
- Aucune
