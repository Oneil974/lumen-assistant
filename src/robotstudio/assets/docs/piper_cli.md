# piper_cli

Speak text using Piper CLI

## Description
Use the Piper command line tool to convert text into speech with a chosen
voice model. Handy for adding spoken feedback to your projects.

## Entrées
- **TEXT**: input_value (type String)
- **MODEL**: input_value (type String)
- **CONF**: input_value (type String)

## Sortie
- Aucune
