# ui_add_image

Add image to canvas

## Description
Place an image on the UI canvas at the size you specify. Ideal for
displaying icons or camera snapshots.

## Entrées
- **ID**: input_value (type String)
- **SRC**: input_value (type String)
- **W**: input_value (type Number)
- **H**: input_value (type Number)

## Sortie
- Aucune
