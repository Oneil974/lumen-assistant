# rpi_camera_video

Record video with Pi camera

## Description
Record a short movie using the Raspberry Pi Camera Module. 
Provide a file name, how long you want to record, and optionally the resolution. 
Great for capturing experiments or streaming footage from your robot. 🎥

## Entrées
- **FILE**: field_input
- **DUR**: field_number
- **W**: field_number
- **H**: field_number

## Sortie
- Aucune
