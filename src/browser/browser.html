● Live — code du site actif
Activer la vue live ?

La vue live charge le site réel et exécute son code (JavaScript), comme un navigateur classique. Le site ne peut pas accéder à Lumen ni à vos données (isolation par origine), mais :

  • n'y saisissez pas d'identifiants ou d'informations bancaires ;
  • le contenu affiché n'est pas filtré (pubs, traceurs, scripts du site) ;
  • en cas de doute, restez en vue lecture (sûre, sans code du site).

Navigateur Lumen

Saisissez une adresse ou une recherche. Le contenu s'affiche en vue lecture (toujours fiable) ; l'IA peut résumer, analyser, traduire et enregistrer la page.
