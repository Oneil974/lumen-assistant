## Comment capturer proprement

- macOS : `⇧⌘4` puis espace pour capturer une fenêtre avec son ombre.
- Pour une capture haute résolution de la fenêtre Lumen sans le bureau,
  utilise un fond uni sombre (#0a0a0f) pour rester cohérent avec la landing.
